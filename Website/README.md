# CourseBuilder Website

Здесь находятся компоненты веб-сайта платформы онлайн-курсов.

Роли пользователей: администраторы, разработчики курсов и студенты. 

Гости могут только смотреть каталог курсов, 
студенты могут приобретать курсы и проходить их, разработчики могут их создавать и редактировать, а администраторы управляют аккаунтами пользователей, рассматривают обращения пользователей

Веб-сайт разработан на Vue.js 3 + TypeScript

Дизайн сделан с использованием Bootstrap 5 + BootstrapVueNext
