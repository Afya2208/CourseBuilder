# CourseBuilder Tests

Здесь находятся автотесты платформы онлайн-курсов.

WebsiteTests (тестирование веб-сайта):
- Правильная авторизация в аккаунт разработчика курсов
- Неправильная авторизация в аккаунт разработчика курсов
- Правильный импорт модулей в курс
- Неправильный импорт модулей в курс
- Правильное создание курса
