# CourseBuilder API

Здесь находятся endpoints, контроллеры, компоненты Web-API платформы.

Компоненты Web-API приложения:
- ASP.NET Core на .NET 10
- СУБД PostgreSQL
- ORM Entity Framework Core 10
- Логирование Serilog

Логирование Serilog:
- в консоль 
- в файлы в папке Logs
